# Site presente de casamento

Página estática feita para a Giovanna, com uma narrativa de amor, galeria de momentos e carta interativa.

## Como abrir

Abra o arquivo `index.html` diretamente no navegador. Não é necessário instalar dependências.

## Como personalizar

- Substitua as quatro URLs de imagens em `index.html` pelas fotos do casal.
- Edite os textos da história e da carta no próprio `index.html`.
- Ajuste a data exibida no cabeçalho e no conteúdo para a data do casamento.

Os estilos estão em `style.css` e a interação da carta está em `script.js`.
